发布到线上

站点是纯静态的，内容存在 assets/js/config.js 里。 下面两条路任选，都只是把这份文件换掉。

为什么推荐这条：浏览器里不存任何令牌，就没有令牌可泄露。 你本来就是用 GitHub 账号登录的状态，2FA 由 GitHub 自己弹，站点完全不接触。

  1. 1复制新的 config.js

    下面这个按钮会把当前编辑好的内容整份复制到剪贴板。

  2. 2打开 GitHub 的编辑页

    在新标签页打开，页面里就是现在线上的那份内容。

    打开 GitHub 编辑页 ↗

  3. 3全选 → 粘贴 → 提交

    在编辑页里按 Ctrl/Cmd + A 全选，Ctrl/Cmd + V 粘贴， 然后点绿色的 Commit changes。约 1–2 分钟自动上线。

令牌只存在这台设备的浏览器里。请用 Fine-grained token， 只授权这一仓库的 Contents: Read and write——这样即使泄露，影响也仅限这个仓库。

    更改管理账户 / 口令

    输入新账户和口令，会生成一行哈希配置。把这行贴进 assets/js/admin.js 顶部的 ADMIN.salt / userHash / passHash 三个位置并提交，新凭据才会对所有设备生效 （仅在本机填写则只对本机有效）。
