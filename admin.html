发布到线上

站点是纯静态的，内容存在 assets/js/config.js 里。 下面三种方式任选——都已把改动写在这份文件里。

  1. 方式一 · 直接在网页里改（最省事，手机也行）

    打开 GitHub 的在线编辑页，全选删除后粘贴下面的内容，点 Commit 即自动上线。

    打开 GitHub 编辑页

  2. 方式二 · 下载后本地提交

    下载替换 assets/js/config.js，然后 git commit && git push。

  3. 方式三 · 一键推送（需要 GitHub 令牌）

    令牌只存在这台设备的浏览器里，不会上传。建议新建一个 Fine-grained token， 仅授权这一个仓库的 Contents: Read and write，随时可撤销。

更改管理账户 / 口令

输入新账户和口令，会生成一行哈希配置。把这行贴进 assets/js/admin.js 顶部的 ADMIN.salt / userHash / passHash 三个位置并提交，新凭据才会对所有设备生效 （仅在本机填写则只对本机有效）。
